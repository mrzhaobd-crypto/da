# 실제 대화와 AI 검토 로그
날짜: 2026-10-29. 과거 대화의 발언을 재구성하지 않았다. 아래 AI 검토 질문 A1~A3은 현재 작업에서 AI가 구성한 분석 질문이며, 학생이 직접 보낸 프롬프트로 표기하지 않는다.

## 현재 작업 지시의 다섯 필드
- 구조: I/S/Q/E/R 다섯 화면. 요청은 api.dart, 상태 조각은 widgets.dart.
- 데이터: topics/questions/results를 로컬 json-server에서 GET. 사용자 입력은 전송하지 않음.
- 예외: 빈 입력, 읽기 중, 오류·재시도, 빈 응답, 좁은 화면.
- 제약: 실제 AI·로그인·결제·채점·영구 저장·상태관리 패키지 없음.
- 확인: 정적 분석, 전체 흐름, 같은 문항 해설, 세 상태와 재시도, 좁은/넓은 레이아웃, Web 빌드.

U0의 논증 보완 요청에 따라 AI가 반론을 제시하고, 학생이 U1 선택·U2 자체 반론·U3 최종 재검토안을 실제로 확인했다. AI 내부 분석 질문은 학생의 원문 요청으로 가장하지 않았다.
