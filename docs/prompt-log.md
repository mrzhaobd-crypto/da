# 실제 대화와 AI 검토 로그

날짜: 2026-10-29. 과거 대화의 발언을 재구성하지 않았다. 학생 발화 U0~U3은 원문의 뜻을 한국어로 옮겨 기록했고, AI 검토 질문 A1~A6은 현재 작업에서 AI가 구성한 분석 질문이다. A1~A6을 학생이 직접 보낸 프롬프트로 표기하지 않는다.

| ID | 요청/입력 | AI 결과·반론 | 판단 | 근거 |
|---|---|---|---|---|
| U0 | 이 내용에 맞춰 코드와 논증을 네가 보완해서 전부 완성해라 | UI-only 구현과 논증 보완 수행 | 작업 범위 수용 | 사용자 요청·공지 |
| U1 | 모두 항상 표시하고 접지 않는다 | 작은 화면의 탐색 부담 반론 제시 | 상시 표시 유지 | 학생 실제 선택 |
| U2 | 너무 번잡해서 중요한 내용을 빠르게 찾기 어렵다 | 정답 우선, 제목·배경·여백으로 구분 제안 | 표현 수정안 | 학생 자체 반론·P08 |

| A6 | 결과 화면에 실제 점수를 표시하는 안을 P01과 범위 관점에서 반박하라 | 실제 점수로 오해, UI-only 범위 초과 | 고정 예시와 예시 표시 유지 | P01 |

## 기록 범위

- U0은 특정 설계 주장에 대한 반론 요청이 아니라 전체 작업 위임이다. 따라서 U0만으로 “AI에게 반론을 요청했다”고 주장하지 않는다.
- U1·U2·U3은 학생이 실제로 선택하고 수정한 범위다. 쟁점 1·2의 근거로 사용한다.
- A1~A6은 AI가 구성한 분석 질문이다. 쟁점 3·4는 AI 검토안이며 학생의 독립 반론으로 표기하지 않는다.
- 쟁점 5·6·7은 학생 요청으로 현재 구현 결정을 정리한 설계 논증이다. 새로운 학생 발화를 만들지 않기 위해 A4~A6으로만 기록하고, U4~U6을 만들지 않았다.
- 원문 발화는 뜻이 바뀌지 않도록 한국어로 옮겼다. 발화의 출처와 판단 범위는 이 문서와 `docs/셀프논증.md`에 함께 남긴다.

## 현재 작업 지시의 다섯 필드

- 구조: I/S/Q/E/R 다섯 화면. 요청은 api.dart, 상태 조각은 widgets.dart.
- 데이터: topics/questions/results를 로컬 json-server에서 GET. 사용자 입력은 전송하지 않음.
- 예외: 빈 입력, 읽기 중, 오류·재시도, 빈 응답, 좁은 화면.
- 제약: 실제 AI·로그인·결제·채점·영구 저장·상태관리 패키지 없음.
- 확인: 정적 분석, 전체 흐름, 같은 문항의 원래 보기·정답·근거, 세 상태와 재시도, 좁은/넓은 레이아웃, Web 빌드.
