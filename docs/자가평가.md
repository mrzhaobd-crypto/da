## 제출 상태

- 개인 GitHub 원격 등록: 완료.
- 원격 clone 검사: GitHub `main`에서 새 경로로 clone한 뒤 `flutter pub get`, `flutter analyze`, `flutter test`, `flutter build web --release`까지 확인했다.
- LMS 제출: 제출자가 확인해야 한다.
- Vercel 배포 가산: 주장하지 않는다.
