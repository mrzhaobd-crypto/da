# 원칙 카드

| 원칙 | 근거 | 적용 | 시연 | 판단 |
|---|---|---|---|---|
| P01 시스템 상태 가시성 | R23의 처리 실패 경험(간접), 고정 예시 범위 | Q-1, C-1/C-3, R-1 | 진행 위치·로딩·빈 결과·예시 표시 | 상태를 구분하여 유지 |
| P03 사용자 통제와 자유 | 결과 화면에서 복습 경로를 선택해야 하는 요구 | R-3, R-4 | 해설 다시 보기·새 강의 입력 | 재진입·복귀 경로 유지 |
| P04 일관성과 표준 | R06의 복습 보기 불일치 | Q-2, E-2 | 같은 문항의 원래 보기·정답·내 선택 | 별도 정답 목록 폐기 |
| P05 오류 예방 | 빈 입력과 선택 누락을 줄이는 요구 | I-1, Q-3 | 입력 오류 안내·선택 전 버튼 비활성 | 입력 즉시 오류 해제, 선택 전 진행 차단 |
| P06 재인 지원 | R06에서 도출한 비교 필요, 학생의 상시 노출 선택 | E-3 | 원문 상시 표시 | 접기 폐기, 기억 부담 감소 목표 |
| P07 유연성과 효율성 | 다음 과업으로 빠르게 이동하는 요구 | S-4, E-4 | 복습 시작·다음 문제 | 한 번의 주 행동으로 이동 |
| P08 미학과 최소 디자인 | 작은 화면에서 정보 위계가 필요하다는 반론 | S-1~S-3, E-2 | 카드·제목·색·여백 | 정보는 유지하고 위계로 탐색 부담 완화 |
| P09 오류 복구 | R23 파싱 실패는 간접 근거, 네트워크는 별도 테스트 | C-2 | 안내·다시 시도·입력 복귀 | 일시 알림만 쓰는 안 폐기 |

효과는 사용자 실험으로 검증하지 않았다. P번호는 닐슨 원칙 번호다.
