# 디자인 가이드

화면 흐름: I → S → Q → E → 다음 Q 또는 R. Navigator.push/pop/popUntil 사용. 공통 C 상태는 별도 제품 화면이 아니라 각 GET 화면의 분기다.
색상: 배경 #F5F7FC, 본문 #18243B, 강조 #4F609B. 본문 16px 이상, 버튼 최소 52px, 화면 여백 24px. 화면 너비 840px 이상 측면 안내. 시스템 글꼴 사용.

## I 강의 입력 · lib/screens/input.dart
목적: 강의 텍스트를 붙여넣고 복습을 시작한다.

내용: 입력 영역, 예시 불러오기, 예시 요약 확인 순서.

의도: 빈 입력은 같은 영역에 안내하며 입력은 전송·저장하지 않는다.

| 번호 | Flutter 위젯 | 비즈니스 명칭 | 원칙 | 정보 기준·편의성·이유 |
|---|---|---|---|---|
| I-1 | TextField | 강의 내용 | P05 | 큰 입력 영역; 빈 입력 안내 |
| I-2 | TextButton | 예시 강의 불러오기 | P06 | 빈 상태에서 시작 부담 감소 |
| I-3 | FilledButton | 예시 요약 확인 | P04 | 실제 AI 생성과 혼동 방지 |

## S 핵심 요약 · lib/screens/summary.dart
목적: 퀴즈 전에 핵심 개념을 확인한다.

내용: 세 주제의 제목·요약·근거와 퀴즈 시작.

의도: 영역 너비 720px 이상은 3열, 좁으면 세로 스크롤.

| 번호 | Flutter 위젯 | 비즈니스 명칭 | 원칙 | 정보 기준·편의성·이유 |
|---|---|---|---|---|
| S-1 | Container + Text | 선언형 UI | P08 | 핵심 제목을 먼저 |
| S-2 | Container + Text | 레이아웃과 제약 | P04 | 주제·요약·근거 순서 반복 |
| S-3 | Container + Text | 수평 프로토타입 | P04 | 동일한 정보 위계 |
| S-4 | FilledButton | 복습 퀴즈 시작 | P03 | 다음 과업으로 이동 |

## Q 복습 퀴즈 · lib/screens/quiz.dart
목적: 스스로 답을 떠올린 뒤 해설을 본다.

내용: 진행 표시, 선택지, 확인 버튼.

의도: 선택 전 진행을 막고 선택 표시만 바꾼다.

| 번호 | Flutter 위젯 | 비즈니스 명칭 | 원칙 | 정보 기준·편의성·이유 |
|---|---|---|---|---|
| Q-1 | Text + LinearProgressIndicator | 문항 진행 안내 | P01 | 현재 위치와 전체 수 |
| Q-2 | OutlinedButton | 보기 선택 | P04 | 하나의 문항 options와 선택 강조 |
| Q-3 | FilledButton | 정답과 해설 확인 | P05 | 선택 전 비활성화 |

## E 정답과 해설 · lib/screens/explanation.dart
목적: 정답의 이유를 강의 근거와 비교한다.

내용: 진행, 문항, 정답·해설, 근거, 다음 행동.

의도: 모든 내용을 항상 표시하고 색·제목·여백으로 나눈다. 접기 없음.

| 번호 | Flutter 위젯 | 비즈니스 명칭 | 원칙 | 정보 기준·편의성·이유 |
|---|---|---|---|---|
| E-1 | Text | 문항 진행 안내 | P01 | 현재 해설 위치 |
| E-2 | Container + Text | 정답과 해설 | P04 | 동일 question의 정답·설명 |
| E-3 | Container + Text | 강의 근거 | P06 | 원문 상시 노출로 기억 부담 감소 |
| E-4 | FilledButton | 다음 문제 / 예시 결과 보기 | P03 | 읽은 뒤 다음 행동 |

## R 예시 결과 · lib/screens/result.dart
목적: 복습할 개념과 재진입 경로를 보여 준다.

내용: 예시 결과, 다시 볼 개념, 해설 재진입, 새 입력.

의도: 결과가 선택과 무관한 고정 예시임을 밝힌다.

| 번호 | Flutter 위젯 | 비즈니스 명칭 | 원칙 | 정보 기준·편의성·이유 |
|---|---|---|---|---|
| R-1 | Text | 예시 결과 안내 | P01 | 실제 채점과 구분 |
| R-2 | Container + Text | 다시 볼 개념 | P06 | 고정 복습 대상 명시 |
| R-3 | OutlinedButton | 해설 다시 보기 | P03 | 복습 재진입 |
| R-4 | FilledButton | 새 강의 입력 | P03 | 첫 화면 복귀 |

## 공통 C 읽기 상태
C-1 LoadingView / CircularProgressIndicator + Text / 읽기 중 / P01: 요청 진행을 알린다.
C-2 ErrorView / Text + FilledButton / 오류와 다시 시도 / P09: 지속되는 설명과 복구 행동.
C-3 EmptyView / Text + TextButton / 빈 목록과 입력 복귀 / P01·P03: 성공한 빈 응답을 연결 실패와 구분.

## 상태관리 포인트(계획)
| 데이터 | 행동 | 표시 위젯 | 범위 |
|---|---|---|---|
| 입력 텍스트 | 입력·예시 | I-1 | 화면 내부 controller |
| 선택한 보기 | 클릭 | Q-2 | setState, 채점 없음 |
| 문항 위치 | 다음 | Q-1/E-1 | 화면 생성 인수 |
| 요청 상태 | GET·재시도 | C-1~3 | FutureBuilder, 화면 내부 |
| 학습 기록 | 향후 완료 | R | 구현하지 않음 |
| 실제 AI 응답 | 향후 생성 | S/Q/E | 구현하지 않음 |
공유 상태관리·쓰기 API·영구 저장은 없다. 현재 로컬 표시와 향후 상태관리 계획을 구별한다.
